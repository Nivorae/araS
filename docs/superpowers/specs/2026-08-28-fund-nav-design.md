# 基金淨值更新 設計文件

**狀態：已實作（2026-08-28）。** 這份記錄的是實作當下驗證過的資料源與坑，不是
提案 —— 之後要改資料源或加功能時，先看這裡再動手。

## 問題

`投資基金` 是唯一有「單位數 × 單價」結構、卻沒有報價來源的投資分類。台股／美股／
加密貨幣／貴金屬都走 Yahoo，基金只能停在成本價，市值與損益永遠是 0。

## 資料源（皆免費、免金鑰、免註冊）

| 範圍                  | 來源                                                   | 端點                                                |
| --------------------- | ------------------------------------------------------ | --------------------------------------------------- |
| 境內（投信基金、ETF） | 投信投顧公會 SITCA，掛在政府資料開放平臺 dataset 11109 | `https://www.sitca.org.tw/MemberK0000/F/03/nav.csv` |
| 境外基金              | 集保結算所 TDCC open data 3-4                          | `https://openapi.tdcc.com.tw/v1/opendata/3-4`       |

2026-08-28 實測：境內 CSV 約 600KB、4,244 檔可用；境外 JSON 約 8.5MB、5,975 檔。

境內原本以為要爬 SITCA 那個 ASP.NET viewstate 網站 —— 不用，公會每天把同一份
資料以 CSV 掛在開放平臺上。TDCC 那邊只有境外基金淨值（3-4）與期信基金淨值
（5-4），**沒有**境內證券投資信託基金。

## 實測踩到的四個坑

1. **境內 CSV 的唯一鍵是「基金統編」，不是「基金代號」。** 基金代號是各投信自己
   的流水號，跨公司會重複（`DDO01` 有十幾家在用）。用它當 key 會把 4,244 檔壓成
   116 檔。
2. **TDCC 用 `-9999` 當「沒有報價」的哨兵值**，不是留空。不擋掉的話畫面會出現
   -9999 的淨值與負市值。
3. **空字串會變成 0。** `Number("")` 是合法的有限數，所以淨值欄必須「非空且
   > 0」才收。
4. **兩份檔案都有 BOM，且位置不同** —— 境內在檔頭（`utf-8-sig`），境外黏在 JSON
   的 key 上（`"﻿基金代碼"`）。

其他形狀差異：境內是「每檔一列」的快照（列上的日期就是那檔的最新淨值日，各家
投信報價時間不同，同一份檔案裡會同時出現兩個日期）；境外是最近數個交易日的整包
歷史，要自己取每檔的最新日期。

## 實作

### 後端 `apps/web/services/funds.service.ts`

- 兩個來源各自下載、解析、以 code 為鍵存成 Map，**模組層記憶體快取 12 小時**。
  刻意不用 Next.js Data Cache：境外那包 8.5MB，超過單筆 2MB 的上限。
- 同一 instance 上的併發查詢共用同一次下載（in-flight map），冷啟動不會拉兩份。
- 兩個來源分開算成敗：一邊掛掉仍然回得出另一邊的結果，兩邊都掛才算失敗。
- 搜尋規則是「查詢字串的每一段都出現在官方名稱裡」，因為使用者輸入的是自己記的
  簡稱（「兆豐第一」），不是官方全名。

### API

- `GET /api/funds/search?q=&limit=` → `FundSearchResult[]`
- `GET /api/funds/quote?code=` → `FundQuote`（查無代碼回 404 `FUND_NOT_FOUND`）

兩支都自我保護（`auth()` 檢查）並列入 `middleware.ts` 的 `auth.protect()` 名單，
與其他市場資料代理一致。

### 代碼儲存

沿用 `Entry.stockCode`，**不需要 migration**：境內存基金統編、境外存 TDCC 基金
代碼。兩邊的代碼空間實測沒有交集，所以不加來源前綴，查詢時先找境內再找境外。

### App

- 詳情頁：`投資基金` 分類顯示「獲取淨值／更新淨值」按鈕。還沒綁代碼時開
  `FundPickerSheet`，用 entry 名稱先搜一次、選定後把官方代碼寫回 `stockCode`，
  之後每次進畫面直接用代碼查。另有「重新選擇基金」可換綁。
- 綁過代碼的基金會併入 `useInvestmentMarketValues`，清單與總覽的市值跟股票同步
  更新；沒綁的沿用成本，與抓不到報價的股票同樣處理。
- 淨值不落地存資料庫（與美股現行模式一致），但**畫面一定要標示淨值日期** ——
  境外基金常落後兩三個交易日，不標會被當成即時報價。

## 明確不做的事（YAGNI）

- 不存歷史淨值、不畫基金走勢圖：淨值日一天一筆，要畫圖得自己累積，值不到那個錢。
- 不做基金配息追蹤：`DividendSection` 仍然只給股票，基金配息的資料源另一回事。
- 不自動比對名稱直接綁定：搜尋結果一律讓使用者確認。同一檔基金常有 A/B/累積/
  配息／不同計價幣別數個類別，猜錯會讓市值默默錯掉。
